## 4. 喷头侧基准（Dimatix Samba Cartridge 规格）

- `Native Drop Volume = 2.4 pL` → `(6V/π)^(1/3) = 16.61 µm`（V = 2400 µm³），
  取整即**喷孔直径 D = 17 µm**（2026-11-05 用户确认）。
- `Dot Size = 30 µm` 是**沉积在基板上的点径**，不是滴径，也不是喷孔径。
- Z 公式中的 D 统一取 **17 µm**；论文的 40 µm 属于 MicroFab 喷头，**不可套用**。
- `Ideal Fluid Requirements`：η **4–8 cps @ 喷射温度**、γ **28–32 dyn/cm**。
  厂商脚注：表面张力超出该范围会导致卫星滴与成滴不良。
- 其余：Addressable Nozzles 12、75 DPI、喷嘴间距 338.67 µm、操作温度 ≤60 °C。

### D 的取法

`Z = √(ργD)/η`，公式中的 D 是**喷孔直径**（PROJECT_RECORD §5.1 用论文 12 组墨水反解 D 全聚在 40 µm 验证过）。
本项目取 **D = 17 µm**，依据为 Samba 规格书的 2.4 pL 原生滴体积 + 用户确认。
规格书未直接印出孔径，但实机液柱宽度剖面（10–16 µm）与 16.61 µm 同量级，可作旁证；
注意该剖面沿轴向变化，**不能**直接当作孔径使用。

- D 差 ±20% → Z 只变 **±9.5%**（平方根依赖）；
- ρ 差 30% → Z 变 **+14%**；
- 故近似 Z 可用于墨水分组与相对排序，**不宜**用于卡 `1<Z<14` 的绝对边界。

目前 ρ/η/γ/D 齐全的墨水有 **六支**（均按 **D = 17 µm**）：

| 墨水 | Z | 用的 η |
|---|---|---|
| `Ag 736465` | **1.63–3.14**（中值 2.17） | 10–18 cps（标称，未注温度） |
| `NOA 89` | **1.18–1.60** | 15–20 cps **@25 °C**（标称） |
| `NOA 89` | **2.97–5.94** | 4–8 cps（按 Samba 喷射温度要求反推） |
| `GZ` / `DIJ-SR200` | **≥1.71–1.78** | <14 cps @50 °C（规格上限，故为 Z **下限**） |
| `GZ` / `DIJ-SR200` | 约 **2.4–4.1** | 若实测温度下 η 降到 6–10 cps |
| `mr-NIL212FC 200nm` | **10.9–13.6**（中值 12.1） | 1.8±0.2 mPa·s @25 °C（实测头温 25.9–30 °C，与标称温度基本一致，口径可直接用） |
| `AF-1` | **≈0.75** | ≈35 mPa·s（未注温度） |

> ⚠️ **η 必须取喷射温度下的值**。NOA 89 的 15–20 cps 是 @25 °C，
> 而实测 HeadTemperature 40–45 °C、Samba 要求 @喷射温度 4–8 cps。
> 两种口径算出的 Z 差 **3.8 倍**：用 25 °C 标称值会把 NOA89 误判到 `1<Z<14` 窗口下沿。
> DIJ-SR 系列同理：规格 η<14 是 @50 °C，而实测温度 58–60 °C，
> η 会更低、Z 更高，故表中 ≥1.7 只是下限。
> **AF-1 是当前最可疑的一支**：η ≈ 35 mPa·s 未注温度，按面值算 Z ≈ 0.75 —— 落在
> `Z<1`「黏性过强、难成滴」区，与实测 90/100 正常单滴**直接矛盾**。
> 若 35 是 @25 °C 标称（AF-1 实测头温 42.7–54.6 °C），喷射温度下 η 会显著更低：
> η≈10 → Z≈2.6、η≈6 → Z≈4.4，才与实测相容。**拿到 AF-1 的温度口径前，Z=0.75 只能当「下限口径」看待。**
> 在拿到喷射温度下的实测黏度前，这些 Z 都只能作区间参考，不能当定值。
