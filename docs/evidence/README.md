### `Table 2 Ranges of each parameter in waveform.ods` — 论文波形参数范围

| 参数              | Low | High |
| --------------- | --- | ---- |
| Voltage (V)     | 10  | 80   |
| Rise time (μs)  | 2   | 40   |
| Dwell time (μs) | 2   | 60   |
| Fall time (μs)  | 2   | 40   |

**支撑 §8 坑 6 的关键对照**：

| 论文           | LP50 Samba（Slewrate 25–55 V/µs，40 V） |
| ------------ | ------------------------------------ |
| 上升时间 2–40 μs | `40 V ÷ 40 V/µs` ≈ **1.0 μs**        |

→ **LP50 的边沿比论文快 2–40 倍**，所以 §8.6 明确「不要复刻论文的上升时间范围」，  
改用 `上升时间 ≈ 电压 ÷ Slewrate` 换算后按 LP50 自身能力域建模。  
论文的电压上限 80 V 也超出 Samba 的 `Pulse0.Voltage` 默认区间（10–40 V）。

### 3.2 实机流程文件与 recipe（`D:\Oleton\Inkjet\LP50 V4730 4-2026 & Canon FAT`）

不是拷贝进本目录的佐证，而是**每次改代码都要回查的真机来源**：

| 文件                                             | 用途                    | 被哪些结论依赖                                                     |
| ---------------------------------------------- | --------------------- | ----------------------------------------------------------- |
| `Recipes/95 ADA/Advanced-Drop-Analysis-*.xml`  | 各喷头可扫维度的**真实**定义      | §2 参数表、§8.7.2 逐喷头参数规模                                       |
| `Recipes/95 ADA/*.recipe.xml`                  | 配方级覆盖值 + **参数命名风格**   | §8.7.2 KM512 默认值陷阱；`ada.py` 的 recipe 生成                     |
| `Rules/Examples/*.RulesConfig.xml`             | DropQCS 判据语法与 8 套预置规则 | §8.5.3 / §8.5.9                                             |
| `Configuration/config/ParameterConfig.par.xml` | 机器侧参数合法范围             | `IO.Ink.PressureSetpoint` = -15.0 mbar（范围 -38…0）→ §8.5 压力取值 |

> **参数命名风格是易踩的坑**：同一批通用参数（`DropAnalysis.X`），  
> 在 DMCSamba / CanonC29 的 recipe 里值与 `.Checkbox` **都带 `[0]`**，  
> 而在 KM512 / KM1024i 的 recipe 里**都不带**；  
> 喷头专属参数（`DropAnalysis.DMC.Samba.*` 等）**一律不带**。  
> 写错了 ADA 会**静默不生效**（扫一个都没跑却不报错）。  
> `ada.py` 的 `recipe_xml()` 已改为从真实 recipe 反查命名，不再手写。

> ⚠️ **`.Nozzle` 参数值必须区分两个概念**（2026-11-03 踩坑后新增，  
> 详见 PROJECT_RECORD §8.6.8 / §8.6.8.1）：

|   |   |   |   |   |
| - | - | - | - | - |

> | 概念       | 出处                           | 语义                  | 例子                             |
> | -------- | ---------------------------- | ------------------- | ------------------------------ |
> | **扫描范围** | flow `<Default>` → recipe 覆盖 | **要测哪些喷嘴**的序列（可为子集） | `1:128`、`1:12`                 |
> | **物理孔数** | 规格书 / 实机配置 / 实测              | 喷头实际有多少喷嘴（硬件事实）     | KM512 = **512**、Samba = **12** |
>
> 佐证：ADA 源码 `Advanced-Drop-Analysis.cs:5140` 把该参数按 **"Active Nozzle"** 序列解析  
> （`:6018` 明确它**按字符串而非数字**解析）⇒ 它是「要测哪些孔」，不是「有多少孔」。  
> 所以同一句 `1:128`：对 Samba（物理 12 孔）是**越界**，  
> 对 KM512（物理 512 孔）是**只测前 1/4**——**两者都不是错**。
>
> 各喷头物理孔数（权威对照，PROJECT_RECORD §8.6.8.1）：  
> Samba **12** / KM512 **512** / KM1024i **1024** / Spectra S-class（SE·SM·SL）**128** /  
> SX3 **128**（已停产）/ Canon C29 **256**。
>
> `1:128` 曾被当成 Samba 的实际孔数写进方案，导致「现有 12 孔只占 9%」的错误结论。  
> `ada.py --verify` 已改为按**物理孔数**校验扫描范围上界，  
> 并把「配方只覆盖部分孔」降级为提示（原先会把合法子集误判成错误）。

### 3.3 `ink_properties.md` — 墨水物性与会话映射（2026-11-05）

`share/` 现有 38 会话 / 437 孔，涉及 6 类墨水。该表登记：
会话前缀 → 墨水型号 → 资料文件的映射、各墨水的 ρ/η/γ、
实测形态与温度压力分布，以及 Samba 喷头侧流体窗口（η 4–8 cps、γ 28–32 dyn/cm）。

支撑 PROJECT_RECORD §5.1 A 类（Z 的四个输入量）与 §8.6.4 的数据现状。
**喷孔直径 D = 17 µm**（2026-11-05 用户确认）：由 2.4 pL 原生滴体积反推
`(6V/π)^(1/3) = 16.61 µm` 后取整；规格书的 `Dot Size 30 µm` 是沉积点径，不是 D。
部分测量会话未勾选的孔按 **NA** 处理，不填 0、不当「不喷」、不进统计。
