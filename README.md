膜层半色调：把连续调厚度图转成 **one-pass 可打印的 1-bit 位图**。
核心是 **ED-FS 误差扩散引擎** + 焊进评测的**打印物理**（膜基 = 非吸收基材、
100% 固含、线性体积叠加）。**项目目标 = 膜层打印**（复刻连续调厚度图），
主线 **1-bit film**，下一步 **多档 film**（多档 ED + 离线优化）。

## 原理

```
连续调厚度图（灰度 = 相对膜厚）
  → ED-FS 逐列串行误差扩散：buf 驱动的落墨决策，量化误差按 FS 权重扩散
    给后续像素（权重和严格 = 1）→ 1-bit 位图（每像素 0/1 滴墨）
  → 物理平均：墨滴铺展（σ≈1.4px 高斯核）线性体积叠加 → 连续膜厚
```

灰度不靠"半滴墨"表达，靠**局部落墨密度**：ED 的串行反馈让邻域被迫选不同值，
亚档位覆盖率是机制的必然结果——dithering 不需要学习。推理无需任何权重/GPU。

膜基物理实测可溯：KM1024iSHE 6 pL 墨滴铺展直径 50 µm → σ = 12.5 µm，
`calc_sigma.py` 出处可查；已验证配方 σ=25µm@1440dpi（=1.42px）。

|---|---|---|

## 用法

```bash
uv sync

# 推理（主引擎 ED-FS；无权重，物理参数即 CLI，默认 film σ=25µm@1440dpi）
uv run python eval.py infer photo.jpg --out out/photo
# 产出 out/photo_bitmap.png（打印位图，**墨=黑/0**）与 out/photo_preview.png

# 三方对照（ED-FS vs Floyd–Steinberg vs Ghostscript 筛网）
uv run python eval.py one   photo.jpg            # 单图 + inkcov 独立审计
```

## 关键物理参数

- `--sigma-um` / `--dpi`：墨滴铺展 σ（µm）与打印分辨率；σ[px]=σ[µm]×dpi/25400。
  **σ<1.4px 时相邻墨滴不融合，one-pass 膜呈麻点**。它们不是画质旋钮，
  必须实测可溯（`calc_sigma.py`）。
- **one-pass 语义**：`ink∈{0,1}` 每像素至多一滴；满覆盖膜厚 `T_max=V/p²`
  （6pL：1440dpi≈19.3µm、2880≈77µm）——**dpi 是量程旋钮，不是精度旋钮**。
  100µm 窗内膜厚波动下限由墨滴数 `k=T̄·s²/V` 决定、与 dpi 无关：薄端细度
  靠档位（路线图 2），不靠 dpi、更不靠 NN。
- `--bias-gain`：ED 偏置增益（默认 4.0，引擎唯一行为参数）。

## 路线图（2026-10-21 重排：无 NN，膜层单线）

1. **ED 引擎升级**（当前最高优先）：蛇形逐行扫描恢复 2D 误差流，目标
   1-bit 纯 ED ≥ PIL FS 25.82；`ed_fs.py` 的 L 维通用，多档白拿。
2. **多档 film**（主线延伸，最大交付形态）：单通道 × 4 档墨量
   （0/⅓/⅔/1 名义值）× FilmSimulator 线性体积；缺的是多档 ED 接线与档位
   实测标定。**验收指标 = 物理尺度均匀性**（100µm 膜厚 RMS + 档位混合统计），
   不是视觉口径——膜层裁判是工艺，高频混合被物理平均掉本就是设计意图。
3. **工艺约束**（最大连续膜厚/台阶覆盖/孤立点）：走离线优化（DBS/CVO 直接
   优化位图，目标函数用 `printer.py` 的物理口径），不训练网络——NN 已证
   负资产（#45/#52）；即便真机物理偏离线性高斯，答案也是"实测核喂优化器"。
4. **档位标定（③）**：4 档实际落墨量是否线性（6pL 喷头档位间常非线性），
   打平铺块 + 扫描/测厚实测；先按名义值跑通，标定作为后续单变量实验。
5. **铺展核实测（②）**：孤点序列打 → 扫描 → 拟合真实核替换高斯假设。
6. ~~网点扩大标定（CMYK LUT256）~~ → 随 CMYK 路线移除（#50）；若多档 film
   需要实测物理，走 4/5 的单通道版本。
